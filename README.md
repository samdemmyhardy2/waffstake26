# WaffStake

A mobile-first sweepstake site tracking yellow and red cards at the 2026 World Cup. Inspired by [The Guardian's player guide](https://www.theguardian.com/football/ng-interactive/2026/jun/04/world-cup-2026-complete-player-guide).

## Features

- Editorial layout with team-by-team player grids
- Search and filter by team
- Tap a player for card details
- Sweepstake: pick your team and track your bank (£10 per yellow, £25 per red)

## Development

```bash
npm install
npm run dev
```

## Data

Edit `src/data/teams.ts` to update squads and card counts as the tournament progresses.
